# সেল মোড + শপ + হালাল বিজনেস (backend ফাইল একই পাথে বসান, app_lib → smart_inventory_app/lib)

## বসানোর পর চালান
    python manage.py migrate            # shop 0002 (অর্ডার আইটেমে সেল মোড)
    python manage.py seed_dry_fruits    # পণ্য + সেল মোড + হালাল বিজনেসের তথ্য (ফাঁকা ঘরে)
    python manage.py seed_halal_business --force   # (ঐচ্ছিক) আগের তথ্য বদলে হালাল বিজনেস বসাতে

## কী বদলেছে
- sales/models.py : ফ্ল্যাট (প্যাক) সেল মোডে পরিমাণ দিয়ে গুণ হতো না — ঠিক।
- shop/*          : শপে প্যাক/ওজন বাটন (কেজি, ৫০০/২৫০/১০০ গ্রাম, কাস্টম গ্রাম ৫০ এর ধাপে)।
                    দাম ও স্টক ProductSaleMode থেকে; অর্ডারে সেল মোড সেভ; Delivered হলে ইনভয়েসেও একই মোড।
- seed_dry_fruits / seed_halal_business : ডেমো পণ্য ও ব্যবসার ডিফল্ট তথ্য।
- app_lib/.../mobile_short_create_pos_sale.dart (দুই কপি) : শর্ট সেলের দামের হিসাব সার্ভারের সাথে মেলানো
  (flat = প্যাক × flat_price; দশমিক পরিমাণ চলবে; "ডজন" মোড আগের মতোই)।

## সীমা (খোলাখুলি)
- Django/Flutter চালিয়ে পরীক্ষা করা হয়নি — শুধু Python syntax যাচাই। আগে ডেমো ডাটাবেসে চালান।
- স্টক এখনো পূর্ণসংখ্যা, তাই যেসব সেল মোডের বেস পরিমাণ পূর্ণসংখ্যা হয় না (যেমন কেজি-বেসে 0.25) শপ সেগুলো দেখায় না। গ্রাম-বেস পণ্যে ঠিক চলে।
- অফলাইন: অ্যাপের _attachBaseQuantities আগে থেকেই সেল মোডের factor ধরে — অপরিবর্তিত; শুধু শর্ট সেলের দাম ঠিক করেছি।

## শপ ↔ অ্যাপ সংযোগ (যাচাই করা)
- অ্যাপের অর্ডার ও শপ সেটিংস স্ক্রিন সরাসরি সার্ভার API (/api/shop/…) থেকে পড়ে, তাই শপ বদলালে অ্যাপে দেখায় — ক্যাশ নেই।
- app_lib/feature/shop/data/shop_models.dart : অর্ডারের আইটেমে সেল মোডের নাম দেখাবে (যেমন "কাঠবাদাম · ২৫০ গ্রাম প্যাক")।
- আগে "অ্যাপ ডায়নামিক নয়" মনে হওয়ার আসল কারণ ছিল পণ্য/সেল মোড: শপ সেল মোড ব্যবহারই করত না (এখন করে)।

## সেল মোড তৈরির স্ক্রিন (app_lib/.../sale_mode_create_screen.dart, দুই কপি)
- Conversion Factor এর হিন্ট বাংলায় স্পষ্ট করা (আপনার ডাটায় "গ্রাম = ৫০০" ভুল ঢুকেছিল) এবং 0 বা ঋণাত্মক মান আটকানো হয়েছে।
- সাধারণ POS স্ক্রিন (mobile_create_sales_pos / desktop create_sales_pos) সেল মোড ব্যবহারই করে না; শুধু শর্ট সেল করে।

## অর্ডারের দাম = ইনভয়েসের দাম (shop/models.py _create_sale)
- Delivered করলে ইনভয়েসে অর্ডারের সময়ের দামই যায় (সেল মোডের দাম পরে বদলালেও)। রাউন্ডিং এর কয়েক পয়সার পার্থক্য ছাড় হিসেবে মিলিয়ে দেওয়া হয়।
- আগের ভার্সনে ফ্ল্যাট (প্যাক) মোডের অর্ডার Delivered করলে প্যাকের দাম বেস পরিমাণ দিয়ে গুণ হয়ে যেত (৫০০ গ্রাম প্যাক ৫০০ গুণ) — এই ফাইলে ঠিক করা আছে। আগের zip বসিয়ে থাকলে এটা দিয়ে বদলান।

## ওয়েবে সেল মোড (Sale ও POS Sale — দুটোই একই sell.js চালায়)
ফাইল: web/static/web/js/sell.js, web/templates/web/sales/pos.html, web/templates/web/sales/new.html
- প্রতিটা সারিতে "Sold by" সিলেক্ট (কেজি / গ্রাম / ২৫০ গ্রাম প্যাক ...)। ডিফল্ট: কোড "kg" থাকলে কেজি, নইলে সবচেয়ে ছোট প্যাক।
- দাম সার্ভারের হিসাবের সাথে মেলানো: flat = প্যাক × flat_price; unit = পরিমাণ × factor × unit_price। গ্রামে +/− বাটন ৫০ করে বাড়ে।
- স্টক যাচাই বেস ইউনিটে (গ্রাম), একই পণ্য একাধিক মোডে থাকলে মোট ধরে।
- সেভ করার সময় sale_mode_id, quantity (মোডের এককে), flat_price/unit_price পাঠানো হয়।
- ওয়েবে আলাদা "শর্ট সেল" পেজ নেই (শুধু অ্যাপে আছে); POS Sale-ই ওয়েবের দ্রুত বিক্রি।
- বসানোর পর ব্রাউজারে Ctrl+F5 দিন (পুরনো sell.js ক্যাশে থাকতে পারে); collectstatic ব্যবহার করলে সেটাও চালান।
- Node দিয়ে হিসাব পরীক্ষা করা হয়েছে (কেজি, ২৫০ গ্রাম প্যাক, কাস্টম গ্রাম, স্টক সীমা); ব্রাউজারে ও Django সার্ভারে সেভ পরীক্ষা করা হয়নি।
